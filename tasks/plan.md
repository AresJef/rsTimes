## 3. 已确认的行为与实现边界

| 决定 | 用户可见结果及验收边界 |
| --- | --- |
| H01 同类比较 | Delta 自身的 `__eq__`、`__ne__` 仅处理 Delta 及继承同样值语义的子类；其他类型返回 `NotImplemented`。相等的同类对象有相同哈希。分别记录双方表达式结果，不把外部对象的反向比较当成 Delta 自身实现。 |
| H02 不可变构造 | `Delta(...)` 的正常参数形式保留，解析和归一化在 `__new__` 完成。已有对象不能通过重复 `__init__`、直接状态恢复等入口改变 15 个值字段。直接调用初始化可能成为无作用的继承方法，或被明确拒绝；不为区分直接调用额外制造复杂状态。 |
| H03 新对象与复用 | 值有变化时产生新对象；值和规定返回类型都不变时可复用原对象。独立构造不做全局对象合并。原有 copy/deepcopy 的独立副本约定保留。 |
| H04 自身保存读取 | 本包的 pickle/copy/deepcopy、子类值和额外状态继续有效；恢复只能创建或完成受控的新对象，不能改已完成对象。错误状态/缓存仍明确报错。不增加旧 cyTimes pickle 或 Cython 兼容，也不额外承诺历史序列化格式互读。 |
| H05 外部转换 | relativedelta 的 weekday 非 None 一律拒绝；leapdays 非零一律拒绝。显式工厂与四个加减方向共用检查；有效但不能表示的规则报 ValueError，源类型错误沿用原类型错误。检查 normalized() 后的实际字段，包含 yearday 隐式产生的 leapdays；不保证任意自定义子类与 dateutil 的所有日期行为相同。 |
| H06 截取与日历 | 保留绝对字段上限截取、负值未设置、毫秒覆盖微秒部分、年月和时钟进位、月底处理及日期最终越界报错。年月小数与绝对字段小数继续原有整数转换规则。 |
| H07 加减与真假 | 相对字段数值加减；绝对字段加法优先右边、减法优先左边，优先方未设置时取另一边。相对部分非零或绝对字段已设置即为 True。月底往返不保证还原；说明 `day=31`/固定日号用法。 |
| H08 小数实验 | 真正保留小数含义的参数限于 weeks/days/hours/minutes/seconds/milliseconds/microseconds。内部仍保存整数。整数部分不能统一转 float；小数余量合并后只在微秒边界统一采用取最近、恰好一半取偶数。NaN/无穷和超范围值明确报错。 |
| H09 64 位实验 | 优先扩大输入及必要中间计算，归一化后有界字段仍可紧凑存储；更大的最终相对年份单独实验。不得通过静默回绕或无检查强转扩大范围。相应 32 位边界变化明确登记，真正溢出仍为 OverflowError。 |
| H10 批量加法 | `delta.apply_many(values)` 等价于逐项 `value + delta`。接收可迭代输入，返回普通 list，保留顺序；空输入返回空 list。支持对应方向已有单项加法支持的日期、时长、Delta、有效 relativedelta 和 NumPy 标量。混合类型允许；不支持的值或运算错误停止调用，不返回半份结果。迭代器已消费部分不回退。 |
| H11 转成标准时长 | `delta.to_timedelta(start=None)` 返回 datetime.timedelta。无起点时只接受没有相对年/月、没有任何绝对设置的 Delta；否则报 ValueError。给定 date/datetime 或已支持子类时返回 `(start + delta) - start`；date 得到整日差，datetime 保留时间影响；同一时区按 Python 钟面差规则。超出 timedelta 范围报 OverflowError，起点运算自身的错误按原规则传播。 |
| H12 文档 | 对外类/方法 docstring 用自然英文、pandas 常见 NumPy 格式，解释怎么用、参数、结果、必要错误和例子；不讲字段打包/原子变量/底层优化，不要求读者查看内部源码。内部维护说明和已有注释保持；修改代码所需安全注释仍按 Rust skill 写。 |

Python 返回 NotImplemented 后仍会尝试外部方法。dateutil 2.9.0.post0 的 `__ne__` 直接反转 `__eq__`，可能让不支持的跨类型 == 与 != 都为 False。按标准协议实施并记录外部限制，不修改或全局补丁外部库。子类重写运算时，批量接口尊重对应 Python 表达式，不为性能跳过用户方法。

依赖 `super().__init__` 重写 Delta 值的旧子类，需要把值构造放到 `__new__`；属于 H02 的明确行为变化，用户说明给一个简单子类例子。本轮不承诺这种旧子类不修改即可继续重写值。

本轮不添加 replace、to_key、to_dict/from_dict、字段提取辅助 API、近似年月时长模式、原生数组输出、异步接口、额外线程/agent、Pydt/Pddt/Parser 迁移、依赖升级或跨平台测试。Pydt 作为已有日期子类参与验收。除上述批准变化外，原接口继续保护。

### 5.2 每个完整组必须满足

- 相同场景的双方/三方共同调用次数 n。短调用批量测总时长再除 n；最快一方初始目标约 1ms，最低 0.2ms。单次完整批量已足够长则 n=1，绝不删减 10000 个元素来凑短窗口。

- 负载/逻辑 CPU≤0.8，可用内存比例≥3%。主机计数达到至少10 tick时，忙碌比例≤75%；不足10 tick时保留“证据不足的诊断”，不当成零负载，也不单凭它否决其他证据充分的组。
- 顺序实际发生、成员/PID/输入/产物匹配，完整组跨度≤250ms。任一成员无效，整组原顺序槽回队；不拼异时单方成绩。合格慢值完整保留。
- 沿用已验证短等待；入口明确不可测时用已冻结短退避，不增加连续空闲等待，不逐批启动系统命令，不暂停其他应用。等待计入工时。
