# Delta 第三轮优化验收

候选92功能、重建安装、77控制与完整首轮通过；独立性能验收与原始证据审计尚待。当前版本为 **0.1.0+delta.3，候选92**。唯一执行状态见 `tasks/todo.md`。

## 目标与已实现功能

在保留已约定日历行为的基础上，使 Delta 的值保持不变、比较和哈希一致，增加批量运算和精确时长转换，并在既有性能保护下支持小数时长与更宽整数。

- 同类 Delta（包括继承相同行为的子类）比较；跨类别返回 NotImplemented。
- `__new__` 完成值构造；重复初始化、属性赋值和直接恢复状态不会改变已完成的值。没有添加 replace。
- relativedelta 的 weekday 和非零 leapdays 明确拒绝；有效绝对字段仍按原有上限限制。
- 保留月底处理、相对进位、绝对字段优先级、真假判断以及子类和时区规则。
- `apply_many(values)` 与逐项 `value + delta` 等价，保留顺序、子类调用和错误行为。
- `to_timedelta(start=None)` 做精确转换，不把月份近似成固定天数。
- 小数时长限定在 weeks 至 microseconds，合并后只在微秒边界取整；整数部分保持准确。整数输入和必要计算扩大到有检查的64位范围，真实溢出仍报 OverflowError。

数值扩展的最终采用仍以两轮性能证明为条件。
