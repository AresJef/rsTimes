```{doctest} delta-month-end
>>> from datetime import date, timedelta
>>> from rstimes import Delta
>>> leap_day = date(2024, 1, 31) + Delta(months=1)
>>> (type(leap_day) is date, leap_day.isoformat())
(True, '2024-02-29')
>>> (leap_day - Delta(months=1)).isoformat()

```
