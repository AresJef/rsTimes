## 实际功能变化

| 变化 | 调用者看到的行为 |
| --- | --- |
| 统一编辑名称 | 九组设置均使用 `add_*`、`del_*`、`set_*`；旧 `remove_*`、`replace_*` 直接移除 |
| 固定偏移命名 | `tz` 改为 `tzoffset`，相关属性与方法同步改名，无旧名别名 |
| 地区时区 | `cfg.add_tzone("Asia/Shanghai")` 在配置时加载标准库 ZoneInfo；parse 复用对象 |
| 文字形式 | 支持空格后缀与 `[Asia/Shanghai]` 后缀；完整名称精确匹配，无 CN 等别名 |
| 时区优先级 | 地区优先于已成功识别的固定偏移，不再比较两者是否一致 |
| 默认忽略时区 | `ignoretz=True` 保持默认；需要时区时传 False；普通未知词仍宽松 |
| 重复当地时间 | datetime default 提供 fold；严格模式缺少选择时报错并说明用法；宽松默认选 1 |
| 不存在当地时间 | 严格模式报错；宽松按真实跳变量及 fold 调整，覆盖一小时及半小时变化 |
| 保存与复制 | 独立快照、可独立编辑的副本；保存名称，恢复时重建 Rust 词表及 ZoneInfo |
| 换环境恢复 | 缺少 ZoneInfo 或地区数据时，一次汇总 RuntimeWarning，保留名称；实际需要缺失地区时明确报错 |
| 状态版本 | 新写 v2，读取当前合法 v1 为无地区设置；更旧的已拒绝状态继续拒绝 |
| 词条冲突 | 八组词表除 jump 外跨组冲突报错；同组允许更新；地区集合按完整名称独立登记 |

Configs 仍不可继承；内部查询不对 Python 开放。default 仍只补年月日，datetime 另外可提供地区 fold；不复制时钟或时区。自定义 dtclass 在最后调用一次。Delta 算法与用户 README 保留。

完整规则见 [批准决定](Parser地区时区与Configs接口决定-20261015.md)；面向调用者的英文例子见 [使用说明](Parser使用说明.md)。
