# rsTimes 0.2.0b1

首个Rust内核beta发行，包含Delta、Configs、Parser、Pydt及重新实现的Pddt。它替代早期0.1.0的发行范围；请明确安装`rsTimes==0.2.0b1`。

## 功能

- Delta支持日历增量、绝对字段、原生归一化、日期互操作和批量应用。
- parse_str、parse、parse_to_epoch共享Rust解析内核，支持配置词表、strict、明确单位及有效Configs地区时区。
- Pydt真正继承datetime.datetime，提供日历、边界、时区和格式操作。
- Pddt真正继承pandas.DatetimeIndex，支持固定单位、纳秒、宽年份、NaT、整列字段/日历/diff，以及明确的DST策略。
- 公开pyi、py.typed、用户文档和许可材料随发行提供。运行时不依赖Babel或Cython。
- 发行验证补齐pandas2.3 Timestamp子类非零纳秒尾数的保留；额外适配在依赖入口准备，pandas3保持原路径。
- Windows编译时从目标Python的公开Unicode规则生成原生字母区间；地区格式用公开系统元数据准备后由Rust读取，不依赖Windows未导出的CPython符号或私有LocaleTime接口。
- 保留已定稿的格式语义：省略年份使用1900，`12:30.5`解释为`12:30:00.500000`；不会随Python3.14／3.15的标准库行为变化而暗改。

## 安装与范围

```sh
python -m pip install "rsTimes==0.2.0b1"
python -m pip install "rsTimes[pandas,polars]==0.2.0b1"
```

普通CPython3.12—3.15；macOS arm64/x86_64、Windows x86_64、Linux x86_64，共16个wheel和1个sdist。macOS部署目标11.0，Linux为manylinux_2_28；实际测试runner和限制见README。不包含PyPy、free-threaded CPython、musl或Windows/Linux ARM。

pandas与Polars保持可选。Pddt的共同默认规则以固定pandas3.0.6为参照，另验证pandas2.3.3兼容路径。PLDT尚未提供。

## 行为说明

- Pddt构造使用`unit`，已有对象通过`as_unit()`显式转换；普通日期运算不自动换单位。
- 可选数字修改参数以`None`表示保留，零不是占位符；整数和真布尔按各自角色校验。
- Parser默认`strict=False, isoformat=True, ignoretz=True`；ISO为优先路径，保留文本时区须明确选择。
- Pydt以标准datetime微秒容量为边界，创建和replace拒绝不存在的地区时间；Pddt保留整列ambiguous/nonexistent策略。
- 这是beta版，不承诺与早期占位发行或冻结cyTimes所有历史行为兼容。

## 产物与验证

所有文件来自本tag的同一源码提交。流水线对实际wheel执行隔离安装、功能和必要集成检查，并对代表sdist进行独立重建和安装验证。随后GitHub Release和PyPI使用同一批已测文件；`SHA256SUMS`与`release-manifest.json`记录源码、构建配置和产物身份。

发布后在16个环境下载PyPI指定版本，核对SHA256、加载位置及关键功能。云runner结果用于功能和安装验收，不冒称正式性能比较。
