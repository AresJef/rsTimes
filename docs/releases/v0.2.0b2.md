# rsTimes 0.2.0b2

This beta makes python-dateutil optional for the core library and expands the
64-bit CPython wheel matrix. Calendar, parsing, timezone and precision semantics
remain unchanged.

## Dependencies

- NumPy 2.5.3 or newer is required.
- Install rsTimes[dateutil] for parserinfo vocabulary import and relativedelta
  integration. Core Configs, parsing, Delta and Pydt work without dateutil.
- Pddt requires optional pandas. The pandas2 compatibility baseline is 2.3.3;
  Python3.15 and Windows ARM64 require pandas3.0.6 or newer.
- Polars input support requires optional Polars2.0.0 or newer. PLDT is not
  implemented.
- Windows installs tzdata2026.5 or newer. Other platforms need system IANA data
  or the optional tzdata package for regional timezones.

## Wheels and verification

The release matrix contains CPython3.12–3.15 for macOS ARM64 and Intel,
Windows x64 and ARM64, and Linux x64/ARM64 with separate manylinux2.28 and
musllinux1.2 wheels:32 native wheels and one complete source distribution.
Only ordinary64-bit GIL-enabled CPython is supported;32-bit Python, PyPy and
free-threaded builds are outside this release.

Release files are built and installed in their native platform/libc environments,
including minimal environments without dateutil and applicable pandas2/3 lanes.
Representative wheels are independently rebuilt from sdist.
The tag binds the exact verified CI run and artifact manifest; GitHub and PyPI
receive those same files without a second release build. SHA256 and build
identities are available in release-manifest.json and SHA256SUMS.
