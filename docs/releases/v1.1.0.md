# rsTimes 1.1.0

This release adds version warnings for the optional pandas and Polars integrations and improves Polars unit conversion diagnostics and help.

## Upgrade

```sh
python -m pip install --upgrade "rsTimes==1.1.0"
```

Keep the extras you use, for example `python -m pip install --upgrade "rsTimes[pandas,polars]==1.1.0"`. The default installation requires NumPy 2.5.3 or newer and packaging 22.0 or newer. Windows also requires tzdata 2026.5 or newer. The pandas, Polars, and python-dateutil integrations remain optional.

## Optional dependency warnings

When `Pddt` or `Pldt` first loads, it checks the installed dependency against the applicable minimum. The category for a low version is `rstimes.errors.DependencyWarning`, a subclass of `UserWarning`. The message names the installed version, the supported minimum, and the pip extra to upgrade. Loading continues under the default warning filters. If `-W error` turns the warning into an exception, the import stops and can be retried after upgrading the dependency or adjusting the filter.

Applications that deliberately run with an older dependency can filter this specific category before loading an adapter.

```python
import warnings
from rstimes.errors import DependencyWarning

warnings.filterwarnings("ignore", category=DependencyWarning)
from rstimes import Pddt
```

- The pandas extra requires pandas 2.3.3 or newer on most supported configurations. Python 3.15 and Windows ARM64 require pandas 3.0.6 or newer.
- The Polars extra requires Polars 2.0.0 or newer. Free-threaded operation requires a compatible upstream runtime. See the [free-threaded setup guide](https://github.com/AresJef/rsTimes/blob/v1.1.0/docs/free-threaded-python.md) for the tested combinations.

## Polars unit conversion

`Pldt.as_unit` and `Series.pldt.as_unit` report the first value that cannot be represented in the requested resolution. The message distinguishes loss of precision from overflow. For an intentionally lossy conversion, `round_ok=True` floors to the earlier output tick, including before the Unix epoch. The class, Series accessor, and Expr accessor each identify themselves when rejecting an invalid `round_ok` argument.

The installed help and type stubs show the required `unit` argument and examples for the class, Series, and Expr APIs. The factory documentation also clarifies unit selection, fractional-second formats, null inputs, and time zone arguments.
