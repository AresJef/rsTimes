# Parser F1：完整性能变化

固定比较对象：当前采用版 parser.4、功能修改后的优化起点 R0，以及同一个最终候选 F1。F1 未重建、未换包；原 B24/B26 失败记录保留并核对校验值。

**结论：完整采集已完成，F1仍未达到全部采用标准。** 相对当前采用版，核心解析基本持平，较长文本有收益；B24、B26仍超过5%保护，C02因波动未明确。相对R0，文本解析和地区解析有收益，但地区8项中的6项未通过稳定性要求，不能将中位提速当成正式通过。采用版保持parser.4。

**下表“+”表示 F1 耗时增加、变慢；“−”表示耗时减少、变快。速度倍率大于 1 表示 F1 更快。** 本次完成采集与是否达到采用门槛分开判断。
