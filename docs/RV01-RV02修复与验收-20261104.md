## 2. RV01：真实pandas Arrow时间戳列

采用一个窄类型适配：真实ArrowExtensionArray＋ArrowDtype的timestamp，通过公开`__arrow_array__`导出一次，再由公开Polars Arrow入口交给现有刻度／validity内核。不新增PyArrow必需依赖，不转成逐行Python datetime。普通DatetimeArray／NumPy／Polars原快路保持。

修复覆盖构造／class parse、fromdate／fromdatetime、combine日期／时钟来源、正向日期相减、eager／Expr diff及Series／Expr combine。空／全缺失仍保声明单位和时区，有效int64 MIN保独立有效位；ns尾数、多chunk／slice／owner和真实异常均有回归。适配限真实timestamp，不扩大到任意Arrow生产者／表。继承Polars的反向相减没有在本轮新增支持。

```python
import polars as pl
from rstimes import Pldt
source = Pldt(pl.Series("t", [-(1 << 63), None, 1],
                        dtype=pl.Datetime("ns", "UTC"))).to_pandas(
                            use_pyarrow_extension_array=True)
Pldt(source).to_physical().to_list()
# 修复前：[None, None, 1]；修复后：[-9223372036854775808, None, 1]
```

工厂角色保持既定差异：fromdate取当地YMD并去源时区；fromdatetime未给目标时保真实瞬间，显式目标替换当地钟表；combine由时钟来源提供时区，即使为空／全缺失，缺乏真实ns信息时仍按既定默认us。原生s时间戳因Polars没有Datetime(s)，经Arrow安全转ms；真实容量超出报OverflowError，不回绕。

## 3. RV02：实际导出绑定及一次owner
