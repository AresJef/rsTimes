# Parser 第二轮优化验收

> 最终结论：本轮全部必要验收通过，已采用 `0.1.0+parser.2`。62项既有性能保护全部通过，ISO与核心组合均达到目标；Configs独立观察项和可选收益的限制如实保留。

本轮目标：保持 `Configs` 和 `parse` 的调用结果、动态配置及自定义日期构造行为，修正已确认的安全问题，优先加快 ISO 和主要解析路径。次要配置优化不挤占主要目标与验收。

## 功能变化与保留行为

| 项目 | 本轮结果 | 用户看到的行为 |
| --- | --- | --- |
| 真正进入时钟字段的超大整数 | 已修正 | `parse("1:4294967297")` 抛出 `ParserFailedError`，其原因是 `OverflowError`，不会悄悄变成日期或零点 |
| 大数字的既有日期解释 | 保留 | `1:2147483647` 及 `4294967297h/m/s` 按原有启发式解释；没有全局禁止大数字 |
| 能计算但超范围的时区配置 | 已修正 | `Configs().add_tz("alias", hours=2**30)` 为 `InvalidConfigsValue`；真正无法转换的整数仍为 `OverflowError` |
| 配置时区与最终日期时区边界 | 保留 | 配置接受正负86400秒；生成带时区日期时，偏移必须严格位于两端之间 |
| 配置类名称 | 统一核对 | 导出、类型提示、docstring、示例及现行说明均使用 `Configs`；另一项目的 `Config` 仅作为外部对照名称 |
| Unicode、动态配置、日期子类和自定义构造函数 | 保留 | 继续按既有兼容规则调用和返回结果 |
| 复制与保存 | 保留 | 浅复制的增删联动、替换后分离、深复制、pickle 和恢复状态行为保持原约定 |
| 重复参数和位置参数过多的两条错误文字 | 保留差异 | 仍为 `TypeError`；PyO3 与官方的文字略有不同，没有为此增加正常调用包装 |
| 超长数字 | 保留安全差异 | 用明确错误代替官方可能出现的崩溃或回绕；未重复运行已知危险的官方输入 |
| 私有状态与公开范围 | 保留 | 使用 rsTimes 自己的 pickle 路径与状态检查；只提供 `Configs` 和 `parse`，不新增 `Parser` 或 `parse_many` |

详细行为决定：[计划 C01–C07](../tasks/plan.md)、[实际行为记录](../tasks/evidence/parser-optimization-20261015/behavior-changes.json)。

## 优化路线的处理

| 优先级 | 路线 | 处理 |
| --- | --- | --- |
| 主要 | ISO 解析 | 完整 ISO 结果减少多余配置检查；已验证的日期字段直接记录，后缀回退规则保留 |
| 主要 | UTC 日期生成 | 零偏移直接使用 UTC 对象，其他偏移保持原构造方式 |
| 主要 | 年内日期与周日期 | 减少逐月查找与重复计算，保持闰年、年界和原有夹取 |
| 主要 | 两位年份 | 已定位：约40微秒主要耗在系统读取本地年份。未找到保持任意时区更新及跨年行为的简单替代方法，停止缓存路线 |
| 次要 | Configs 构造、重置与 parserinfo | 默认规则只读共享，首次写入时复制；保留浅复制共享的外层关系，没有绕过子类构造 |
| 次要 | 普通默认规则查询 | 未传入配置时直接读取私有不可变规则；用户配置及动态行为保留原路径 |
| 次要 | ASCII 设置及第三方小幅差距 | 复用已有栈键与字符变体优化；不再新增设置特化，也不按 Pydt 类名写专用捷径 |
| 已撤回 | 每段数字预先选择字符宽度 | 开发实测没有可靠收益，已撤回；字符串读取文件与旧版源码一致 |

以上开发筛选只决定哪些代码进入最终候选，不代替下面的正式验收。

### 覆盖和质量审计

主轮与独立轮各9个新测量周期，每周期三方各一个独立worker，共54个真实测量PID。每项每轮108个完整三方组，双轮216组；76项共**16,416个合格三方组**。Delta三个调用各有双轮432对，共**1,296个合格两方组**，复用同周期旧／新Rust worker。

三方尝试16,642组，按固定质量规则未接收226组；Delta尝试1,303对，未接收7对。失败均整组回队；所有合格快慢值均保留，未按性能胜负筛选。每批至少5毫秒，边界、线程CPU和误差规则不变；IPC在目标计时外、在整组跨度内。批内重复公开调用并释放结果，再除以调用次数得到单次平均。

完整采集实耗**28.41分钟**，主轮／独立轮均完整结束。预热、初始控制和正式数据分开；两次计划内质量调整合计34.67秒，仅凭实测精度改善采用。B33和U08固定紧邻预热计数已入冻结记录，并由原始数据审计核对。时钟检查不保证消除所有频率、缓存和温度影响，所以仍严格保留稳定性判定。
